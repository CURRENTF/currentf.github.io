I am a Ph.D. student in Intelligent Science and Technology at Harbin Institute of Technology (Shenzhen), supervised by Prof. Jun Yu and Prof. Qiang Huang. I study LLM architectures and efficient training and inference, including long-context serving, sparse inference engines, unified multimodal models, and streaming video understanding.

ICLR 2026 Multimodal

Uni-X: Mitigating Modality Conflict with a Two-End-Separated Architecture for Unified Multimodal Models

Jitai Hao*, Hao Liu*, Xinyan Xiao, Qiang Huang, Jun Yu
Overview PDF OpenReview Code
TL;DR: 提出“中间共享、两端分离”架构，缓解统一多模态模型中的模态冲突；Uni-X-3B 匹配当时 7B SOTA 模型的性能。积累了多机多卡训练经验（32 卡 H800）。
TL;DR: A shared-middle, separated-ends architecture mitigates modality conflict, with Uni-X-3B matching contemporary 7B state-of-the-art models. This work gave me multi-node training experience on 32 H800 GPUs.
NeurIPS 2025Spotlight · Top 3.2% Efficiency

A Token is Worth over 1,000 Tokens: Efficient Knowledge Distillation through Low-Rank Clone

Jitai Hao, Qiang Huang, Hao Liu, Xinyan Xiao, Zhaochun Ren, Jun Yu
Overview PDF Code Zhihu
TL;DR: Low-Rank Clone（LRC）仅训练一组低秩投影矩阵，使用仅 10B-20B tokens 即可从头训练、蒸馏出高性能小语言模型，达到与使用数万亿 tokens 预训练的模型相当的性能。
TL;DR: Low-Rank Clone trains only low-rank projection matrices, using just 10B-20B tokens to train a high-performing small language model from scratch through distillation, competitive with models pretrained on trillions of tokens.
ICLR 2025 Efficiency

OmniKV: Dynamic Context Selection for Efficient Long-Context LLMs

Jitai Hao*, Yuke Zhu*, Tian Wang, Jun Yu, Xin Xin, Bo Zheng, Zhaochun Ren, Sheng Guo
Overview PDF Code Zhihu
TL;DR: 首次提出跨层注意力索引复用，利用层间注意力相似性，结合动态上下文选择与 KV-cache offloading，在保留完整历史信息的同时降低长上下文推理成本。
TL;DR: Pioneered cross-layer attention-index reuse, combining inter-layer attention similarity, dynamic context selection, and KV-cache offloading to reduce long-context inference cost while retaining the full history.

The idea was cited by Zhipu's IndexCache (IndexShare) and adopted in foundation models, including GLM-5.2, GLM-5.3, Hy4, and DeepSeek-V4.1.

相关思路被智谱 IndexCache（IndexShare） 引用并应用于基础模型，包括 GLM-5.2、GLM-5.3、Hy4、DeepSeek-V4.1。

arXiv 2026 ICLR 2027 · Under review ICLR 2027 · 在投 Sparse inference

SparseEngine: Sparse-First Inference Engine

Jitai Hao*, Quansheng Gu*, Qiang Huang, Jun Yu
arXiv PDF Code
TL;DR: Designed around sparsity as a first principle, co-optimizing sparse attention, KV-cache management, and execution across 15 sparse methods. It delivers over 10× decode throughput with KV eviction and over 2× end-to-end agent speedup while maintaining method quality.
TL;DR: 以稀疏性为第一性设计原则，协同优化稀疏注意力、KV 缓存管理与执行流程，统一支持15 种稀疏方法。在保持方法质量的实验设置下，KV 淘汰场景 Decode 吞吐提升超过 10×，Agent 基准端到端加速超过 2×。
arXiv 2026 ICLR 2027 · Under review ICLR 2027 · 在投 Streaming video

ShallowStream: Index Shallow then Answer Deep for Streaming Video Understanding

Jitai Hao*, Ke Yang*, Di Yan, Fan Liu, Qiang Huang, Jun Yu
arXiv PDF Code
TL;DR: Index with shallow layers, answer with the full model. A lightweight video index supports evidence retrieval at query time, reducing stream-processing time to about one third.
TL;DR: 提出浅层定位证据、完整深层回答：以浅层 KV 建立轻量视频索引，提问时检索相关证据并执行完整深层推理，将视频流式处理时间缩短至约 1/3。
arXiv 2026 ICLR 2027 · Under review ICLR 2027 · 在投 Agentic serving

Can Agent Harnesses and Inference Engines Hear Each Other? The HEAR Protocol for Agentic LLM Serving

Jiaqi Zhao*, Haodong Chen*, Jitai Hao*, Wei Zhao, Jinghao Pang, Qiang Huang, Jun Yu
arXiv PDF
TL;DR: I originated the core idea and led the project. HEAR provides a bidirectional harness-engine protocol, exposing prefix-cache matches and engine load so agents can schedule requests more intelligently and smooth workload peaks.
TL;DR: 我提出核心 idea 并负责项目。HEAR 构建 Agent 应用与推理引擎之间的双向通信协议，让应用获知当前请求可命中的 prefix cache 与引擎负载，从而更智能地排布请求、削峰填谷。
arXiv 2026 IEEE TPAMI · Under review IEEE TPAMI · 在投 KV compression

ResidualKV: Residual-Based KV Cache Compression for Efficient Long-Context Inference

Jitai Hao, Qiang Huang, Yaowei Wang, Min Zhang, Jun Yu
Overview概览 arXiv PDF Code
TL;DR: Formerly DeltaKV. Encodes each token as reference KV + quantized residual and reconstructs selected states on demand, shrinking KV storage to as little as about 1/8 with near-lossless quality. Revised LongBench results use 13%-16% KV storage and 30% attention computation.
TL;DR: 原名 DeltaKV。将 token 的 KV 表示为reference KV + 量化 residual，按需重建选中的状态，在接近无损质量下将KV 缓存最低约为原来的 1/8。修订版 LongBench 实验使用 13%-16% 的 KV 存储与 30% 的注意力计算。
arXiv 2026 Under review 在投 Safety alignment

Beyond Refusal Patterns: Safe-Role Internalization for Robust and Generalizable LLM Safety Alignment

Jinghao Pang*, Jitai Hao*, Qiang Huang, Zhaochun Ren, Jun Yu
arXiv PDF
TL;DR: Supervised Safe-Role Fine-Tuning (SSRFT) teaches models to internalize a safe role, improving robustness to jailbreaks and generalization to unseen attacks while reducing over-refusal.
TL;DR: 提出 Supervised Safe-Role Fine-Tuning（SSRFT），通过内化安全角色提升对越狱攻击的鲁棒性和对未见攻击的泛化能力，并减少对正常问题的过度拒答。
